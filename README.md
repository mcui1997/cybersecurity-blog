# patch notes

One security story a month, explained by an engineer.

**Live:** [mcui1997.github.io/cybersecurity-blog](https://mcui1997.github.io/cybersecurity-blog/) · **Portfolio:** [mcui1997.github.io/portfolio](https://mcui1997.github.io/portfolio/)

## New post

1. Copy any file in `posts/` to `posts/YYYY-MM-name.md`
2. Edit the frontmatter and text
3. Push to `main` and it deploys

Unfinished posts go in `drafts/`.

## Run locally

```
npm install && npm run dev
```
